3. Concurrency and performance: PostgreSQL uses Multi-Version Concurrency Control (MVCC) to handle concurrent transactions efficiently, allowing for high performance even under heavy workloads.

what is MVCC?
MVCC stands for Multi-Version Concurrency Control. It is a database management technique used to handle concurrent transactions in a way that allows multiple transactions to access the same data simultaneously without conflicts. MVCC works by creating multiple versions of data records, allowing transactions to read and write without blocking each other. When a transaction modifies a record, it creates a new version of that record, while other transactions can continue to access the previous version until they are ready to commit their changes. This approach helps improve performance and allows for better concurrency in database systems like PostgreSQL.

example of mvcc using phonepe transactions
Transaction 1: User A initiates a payment of $100 to User B.
Transaction 2: User C initiates a payment of $50 to User D at the same time.
In a traditional locking mechanism, Transaction 1 would lock the relevant records until it completes, causing Transaction 2 to wait. However, with MVCC, both transactions can proceed concurrently. When Transaction 1 modifies the records for User A and User B, it creates new versions of those records. Transaction 2 can read the previous versions of the records for User C and User D without waiting for Transaction 1 to finish. This allows both transactions to execute simultaneously without blocking each other, improving performance and user experience.


my doubt is if transaction 2 user b send the amount user c then what will happen in that case?
In the case where Transaction 2 (User C sending $50 to User D) occurs while Transaction 1 (User A sending $100 to User B) is still in progress, MVCC allows both transactions to proceed without blocking each other.
When Transaction 1 modifies the records for User A and User B, it creates new versions of those records. Transaction 2 can read the previous versions of the records for User C and User D without waiting for Transaction 1 to finish. This means that Transaction 2 can successfully execute and update the records for User C and User D while Transaction 1 is still in progress. Once Transaction 1 completes and commits its changes, the new versions of the records for User A and User B will become visible to other transactions, including Transaction 2. This allows for concurrent execution of transactions without blocking, improving performance and user experience in the database system.

what is special feature in sql also indexing is present
Yes, indexing is a feature that is present in both SQL and PostgreSQL. Indexing is a database optimization technique that allows for faster retrieval of data by creating a data structure that improves the speed of data retrieval operations on a database table. Both SQL and PostgreSQL support various types of indexes, such as B-tree, hash, and GIN indexes, which can be used to enhance query performance based on the specific use case and data characteristics. However, PostgreSQL offers additional advanced indexing options and features compared to some other SQL databases, making it more versatile for handling complex queries and large datasets.

what is b-tree index?
A B-tree index is a type of data structure used in databases to improve the speed of data retrieval operations. It is a balanced tree structure that allows for efficient searching, insertion, and deletion of records. In a B-tree index, data is organized in a hierarchical manner, with each node containing multiple keys and pointers to child nodes. The keys in the B-tree index are sorted, which allows for fast searching by traversing the tree from the root to the leaf nodes. B-tree indexes are commonly used in databases like PostgreSQL to optimize query performance, especially for range queries and equality searches on indexed columns.
example of creating a B-tree index in PostgreSQL:
CREATE INDEX idx_users_email ON users USING btree (email);

what is hash index?

it will work like a hash table where it will create a hash value for each record and it will store the hash value in the index. It is used for equality searches and it is not suitable for range queries. Hash indexes are generally faster than B-tree indexes for equality searches but they do not support range queries or sorting.


what is GIN index?

GIN is defined as Generalized Inverted Index. It is a type of index used in PostgreSQL to efficiently handle complex data types, such as arrays, JSON, and full-text search. GIN indexes are designed to support queries that involve searching for specific values within these complex data types. They work by creating an inverted index that maps the values in the indexed column to the rows that contain those values. This allows for fast retrieval of rows based on the presence of specific values within the indexed data. GIN indexes are particularly useful for improving performance when querying large datasets with complex data structures.

what is GIST index?

GIST stands for Generalized Search Tree. It is a type of index used in PostgreSQL to support complex data types and queries, such as geometric data, full-text search, and custom data types. GIST indexes are designed to handle a wide range of query types and can be used for both equality and range queries. They work by creating a tree structure that allows for efficient searching and retrieval of data based on the indexed values. GIST indexes are particularly useful for improving performance when working with spatial data, full-text search, and other complex data types in PostgreSQL.

try:
    conn = mysql.connector.connect(**db_config)
    cursor = conn.cursor()

    for index, row in df.iterrows():
        issue_name = str(row["Issue Name"]).strip()
        batch_name = str(row["Batch Name"]).strip()
        issue_names.add(issue_name)

        zone_overlap = str(row["Zone Overlap"])  # e.g., "6,10"

        if zone_overlap.strip() and zone_overlap.lower() != "nan":
            # Split pages
            pages = [p.strip() for p in zone_overlap.split(",") if p.strip().isdigit()]
            for page in pages:
                page_number = int(page)

                # Source and destination paths
                src_dir = os.path.join(base_path, batch_name, issue_name, "backup", "finish-zoning")
                dst_dir = os.path.join(base_path, batch_name, issue_name)

                # File name format: IssueName-PageNumber.xml
                file_name = f"{issue_name}-{page_number:05d}.xml"

                src_file = os.path.join(src_dir, file_name)
                dst_file = os.path.join(dst_dir, file_name)

                # Copy if exists
                if os.path.exists(src_file):
                    subprocess.run(["cp", src_file, dst_file], check=True)
                    os.chmod(dst_file, 0o777)  # give full permissions
                    print(f"Copied: {src_file} -> {dst_file}")

                    # Update DB immediately after copy
                    sql = """UPDATE coc_issue_info SET cii_process_id='25',cii_lock_status='0' WHERE cii_issue_name = %s AND cii_batch_name = %s"""
                    cursor.execute(sql, (issue_name, batch_name))
                    print(f"DB updated for issue: {issue_name}, batch: {batch_name}")
    
                else:
                    print(f"File NOT found: {src_file}")

    conn.commit()
    cursor.close()
    conn.close()
    print("\nAll DB updates committed successfully.")

except mysql.connector.Error as err:
    print(f"Database error: {err}")

# ==== Final print ====
print("\nFinal Issues:", ",".join(issue_names))

what is url encoded data format?
URL-encoded data format is a way to encode key-value pairs in a format that can be safely transmitted in a URL or as part of an HTTP request body. In this format, special characters are replaced with a percent sign (%) followed by two hexadecimal digits representing the ASCII code of the character. For example, spaces are encoded as %20, and the ampersand (&) is encoded as %26. This encoding is commonly used when submitting form data in web applications or when sending data in HTTP requests, ensuring that the data is properly formatted and can be correctly interpreted by the server.

example of url encoded data format:
title=My%20First%20Post&body=Hello%20from%20Postman&userId=1

after url decoding it will look like this:
title=My First Post&body=Hello from Postman&userId=1

why we need url encoding?
URL encoding is necessary to ensure that special characters in data are properly transmitted and interpreted in URLs and HTTP requests. It prevents issues that can arise from characters that have special meanings in URLs (like &, ?, /) or that may not be allowed in URLs (like spaces). By encoding these characters, we can ensure that the data is transmitted correctly and that the server can accurately parse and process the information being sent in the request.

what is difference between redis and memcached?
Redis and Memcached are both in-memory data stores used for caching, but they have some key differences:
1.Redis supports a wider range of data structures (strings, hashes, lists, sets, sorted sets) while Memcached primarily supports key-value pairs.
2.Redis provides persistence options (RDB snapshots, AOF logs) to save data to disk, while Memcached is purely in-memory and does not offer persistence.
   RDB snapshots means Redis can take periodic snapshots of the in-memory data and save it to disk, allowing for data recovery in case of a crash. AOF (Append Only File) logs every write operation received by the server, which can be replayed to reconstruct the dataset after a restart.
3.Redis has built-in replication and high availability features, while Memcached does not have native support for replication or clustering.
4.Redis supports Lua scripting for complex operations, while Memcached does not have scripting capabilities.
5.Redis is often used for more complex use cases that require advanced data structures and persistence, while Memcached is typically used for simple caching scenarios where high performance is the primary concern.

#######INHERITANCE#######
Inheritance is a feature of object-oriented programming that allows a new class (called a child class or subclass) to inherit attributes and methods from an existing class (called a parent class or superclass). This promotes code reusability and establishes a natural hierarchical relationship between classes.

for example:
class Animal:
    def eat(self):
        return "Eating..."

class Dog(Animal):  # Dog is inheriting from Animal
    def bark(self):
        return "Woof!"

In this example, the Dog class inherits the eat method from the Animal class. This means that an instance of the Dog class can call both the eat method (inherited from Animal) and the bark method (defined in Dog).

my_dog=Dog()
print(my_dog.eat())

why we need inheritance? means

1. Code reusability: Inheritance allows us to reuse code from existing classes, reducing redundancy and improving maintainability.
2. Logical hierarchy: It helps to establish a natural hierarchical relationship between classes, making it easier to understand and organize code.
3. Extensibility: Inheritance allows us to create new classes that extend the functionality of existing classes without modifying the original class, which promotes flexibility and scalability in software design.

super() function in inheritance:::
The super() function in Python is used to call a method from the parent class in a child class. It allows you to access and invoke methods of the superclass without explicitly naming it, which is especially useful in cases of multiple inheritance. The super() function is commonly used in the __init__ method of a child class to ensure that the initialization code of the parent class is executed.

for example:
class Animal:
    def __init__(self, name):
        self.name = name
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)  # Call the __init__ method of the parent class (Animal)
        self.breed = breed
In this example, the Dog class inherits from the Animal class. The __init__ method of the Dog class uses super() to call the __init__ method of the Animal class, ensuring that the name attribute is properly initialized for instances of the Dog class.

what if we dont use super() in the child class::
If you don't use super() in the child class, the __init__ method of the parent class will not be called automatically, and any initialization code defined in the parent class will not be executed. This means that attributes defined in the parent class may not be properly initialized for instances of the child class, which can lead to errors or unexpected behavior when you try to access those attributes.so name will not be initialized for the Dog class and it will raise an error when you try to access the name attribute of a Dog instance.

###################################################DJANG0#############################################################################

Django is  a python framework which makes easier to create sites using python.
Django emphasizes reusability and "pluggability" of components, rapid development, and the principle of "don't repeat yourself". It follows the model-template-view architectural pattern.

##HOW DJANGO WORKS?
1. Django works on model-template-view architectural pattern. It is a software design pattern that separates the data (model), the user interface (template), and the control logic (view) into three distinct components.

model - the data you want to store in the database
view - the logic that handles the request and returns a response
template - the HTML file that defines the structure of the webpage

##########Model

#In django the data is delivered as a Object Relational Mapper (ORM) which is a way to interact with the database using python code instead of writing raw SQL queries. It allows you to define your data models as python classes and then automatically generates the database schema and provides an API to interact with the database.

example of model in django:

from django.db import models
class Book(models.Model):
    title = models.CharField(max_length=100)
    author = models.CharField(max_length=100)
    published_date = models.DateField()

    #inserting data into the database
    book = Book(title="The Great Gatsby", author="F. Scott Fitzgerald", published_date="1925-04-10")
    book.save()

#It will create a table in the database with the name of the class and the fields as columns and it will insert the data into the table.
#Due to these ORM we can easily interact with the database without writing raw SQL queries and it will also help us to avoid SQL injection attacks.


##########VIEW

A view is a function or method that takes a web request and returns a web response. It is responsible for handling the logic of the application and interacting with the model to retrieve or manipulate data.

The views are located in a file called views.py in the app directory. A view can be a function-based view or a class-based view.

##########TEMPLATE

A template is an HTML file that defines the structure of the webpage. It is responsible for rendering the data passed from the view into a format that can be displayed in the browser.
The templates are located in a directory called templates in the app directory. A template can use template tags to display data and control the flow of the template.

#########URLS

In django the urls are defined in a file called urls.py in the app directory. It is responsible for mapping the URLs to the views. It uses regular expressions to match the URLs and then calls the corresponding view.

example of urls.py
from django.urls import path
from . import views

urlpatterns = [
    path('books/', views.book_list, name='book_list'),
    path('books/<int:id>/', views.book_detail, name='book_detail'),
]

#######
So what is the process going on means
When you have installed Django and created your first Django web application, and the browser requests the URL, this is basically what happens:

Django receives the URL, checks the urls.py file, and calls the view that matches the URL.
The view, located in views.py, checks for relevant models.
The models are imported from the models.py file.
The view then sends the data to a specified template in the template folder.
The template contains HTML and Django tags, and with the data it returns finished HTML content back to the browser.

###########################################################LINKED LIST#############################################################################

Array or list will store elements in continous memory allocations but linked list will stores an elements in random memory locations and stores the next element memory locations.

Each element in a linked list contains two nodes one contains data and other node contains memory location of next element.

TYPES OF LINKED LIST:::
1. SINGLE LINKED LIST
2. DOUBLE LINKED LIST ---In Double linked list each node has the links to front element and back element.
3. CIRCULAR LINKED LIST --- In circular linked list first node and last nodes are connected.

starting node is called as head node and last node is called as tail node


advantages and disadvantages::

*compare to array linked list size we can increase because arrays are fixed size.
*Insertion for linked list is O(1) but array is O(n)
*For accessing in linked list is O(n) but in array is O(1) if array we access through index.
*for linked list we need extra space for pointers
*It will efficient for dynamic data.

##########################################################MULTITHREADING IN PYTHON######################################################################

what is process and thread?
*Process is an instance of a program that is being executed. It has its own memory space and resources. It is an independent entity that can run concurrently with other processes.
 It is running independently and it is not affected by other processes. It is a heavy weight process because it requires more resources and time to create and manage.
*Thread is a smaller unit of a process that can run concurrently with other threads within the same process. It shares the same memory space and resources as the parent process.


##WAITING for I/O requirements so it will increase execution time of program but if we use multithreading it will not wait for I/O requirements and it will execute other threads while waiting for I/O requirements.
what are the I/O requirements?
*I/O requirements are the operations that require input/output operations such as reading/writing files, making network requests, etc. These operations can take time to complete and can block the execution of the program. Multithreading allows the program to continue executing other threads while waiting for these I/O operations to complete, improving overall performance and responsiveness.

for multithreading in python
1.we need to know when we need to use multithreading
2.I/O requirements :Tasks that spend more time waiting for I/O operations than performing computations are good candidates for multithreading. Examples include file handling, network requests, and database operations.
3.concurrent execution: If you have multiple tasks that can run concurrently and do not depend on each other, multithreading can help improve performance by allowing them to execute simultaneously.

Multiprocessing means each process will run independently and it will not affect other processes. It is a heavy weight process because it requires more resources and time to create and manage.

#################################################################################PROCESSPOOL EXAMPLE####################################################################
#ProcessPool is a higher-level abstraction for managing a pool of worker processes. It allows you to easily execute tasks concurrently across multiple processes, which can take advantage of multiple CPU cores and improve performance for CPU-bound tasks. The ProcessPool class is part of the concurrent.futures module in Python. It provides a simple interface for submitting tasks to a pool of processes and retrieving their results. 
#For example, if you have a function that performs a CPU-intensive calculation and you want to execute it concurrently for a list of inputs, you can use a ProcessPool to manage a fixed number of worker processes that will execute the function concurrently for each input in the list.

from concurrent.futures import ProcessPoolExecutor
import time

def cpu_intensive_task(n):
    # Simulate a CPU-intensive task
    result = 0
    for i in range(1, n + 1):
        result += i ** 2
    print(f"Sum of squares up to {n} is {result}")
    return result
#give list with 100 large numbers to process
numbers = [1000000, 2000000, 3000000, 4000000, 5000000, 6000000, 7000000, 8000000, 9000000, 10000000,
           11000000, 12000000, 13000000, 14000000, 15000000, 16000000, 17000000, 18000000, 19000000, 20000000]
start = time.time()
with ProcessPoolExecutor(max_workers=2) as executor:
    results = list(executor.map(cpu_intensive_task, numbers))
print(f"Results: {results}")
print(f"Time taken with ProcessPoolExecutor: {time.time() - start}")

When you are working related to text for training the model then it is better to divide that text to chunks because ai can't able to read all words at a time.

Imagine your PDF has 1000 words. AI models cannot read 1000 words at once — they have a limit of around 200-400 words at a time

By default chunk size is 200 words.


def chunk_text(text, chunk_size=200, overlap=50):
    words  = text.split()
    chunks = []
    i = 0
    while i < len(words):
        chunk = " ".join(words[i:i + chunk_size])
        chunks.append(chunk)
        i += chunk_size - overlap
    return chunks

1.####MISIING VALUES
we can handle missing values in three mechanisms
##MCAR (Missing Completely at Random): The missingness is completely random and unrelated to any other variable in the dataset. For example, if a survey respondent accidentally skips a question, the missing data is MCAR.there is no reason or relationship between the missing data and any other variable in the dataset. In this case, the missing data can be safely ignored or imputed without introducing bias.
##MAR (Missing at Random): The missingness is related to other observed variables in the dataset but not to the missing variable itself. For example, if older respondents are more likely to skip a question about technology usage, the missing data is MAR. In this case, the missing data can be imputed using the observed variables that are related to the missingness, such as age.
second example of mar is if i am conducting survey men will disclose Salary and women not disclose their age so these two can miss and also it comes under mar because it is related to other observed variables in the dataset but not to the missing variable itself.
##MNAR (Missing Not at Random): The missingness is related to the missing variable itself. For example, if people with higher incomes are less likely to disclose their salary, the missing data is MNAR. In this case, the missing data cannot be safely ignored or imputed without introducing bias, as the missingness is directly related to the variable of interest.It is dependent on another variable in the dataset. For example, if people with higher incomes are less likely to disclose their salary, the missing data is MNAR. In this case, the missing data cannot be safely ignored or imputed without introducing bias, as the missingness is directly related to the variable of interest.

WORD EMBEDDINGS::
Word embeddings are a way to represent words as dense vectors in a continuous vector space. They capture the semantic meaning of words by placing similar words closer together in the vector space. For example, in a word embedding space, the words "king" and "queen" would be close to each other, while the word "apple" would be farther away. Word embeddings are typically learned from large corpora of text using algorithms like Word2Vec, GloVe, or FastText. These embeddings can then be used as input features for various natural language processing tasks such as text classification, sentiment analysis, and machine translation. By using word embeddings, models can better understand the relationships between words and improve their performance on NLP tasks.

For example, if you have a sentence like "The cat sat on the mat", you can represent each word as a vector in a high-dimensional space. The word "cat" might be represented as a vector that captures its meaning and relationships to other words. If you have another word like "dog", it would be represented as a different vector, but it might be close to the "cat" vector because they are both animals. On the other hand, a word like "car" would be farther away from "cat" and "dog" in the embedding space because it has a different meaning. This way, word embeddings allow models to understand the semantic relationships between words and improve their performance on NLP tasks.


# word embeddings are two types:
1.Count or Frequency-based embeddings: These embeddings are created based on the co-occurrence of words in a large corpus of text. They capture the statistical properties of words and their relationships based on how often they appear together. Examples include Word2Vec and GloVe. (TIF IDF,BOW)
2.Deep Learning-based embeddings: These embeddings are learned using deep learning models, such as neural networks. They capture the semantic meaning of words by training on large amounts of text data. Examples include FastText and BERT.(word2vec, glove, fasttext, bert)

####WORD2VEC############
1.CBOW(continous bag of words): In this approach, the model predicts a target word based on its surrounding context words. For example, given the sentence "The cat sat on the mat", if we want to predict the word "sat", the model would take the context words "The", "cat", "on", "the", and "mat" as input and try to predict "sat". The idea is that words that appear in similar contexts will have similar embeddings.
2.Skip-gram: In this approach, the model predicts the surrounding context words based on a target word. For example, given the same sentence "The cat sat on the mat", if we want to predict the context words for the target word "sat", the model would take "sat" as input and try to predict the context words "The", "cat", "on", "the", and "mat". The idea is that words that have similar meanings will have similar embeddings because they will appear in similar contexts.

For missing the data there is no reason or pattern to miss the data. values are missing randomly in the dataset.

And also the missing values not depends on variables.

2. MAR(Missing at random)::

Data is missing at randomly but here difference between  MAR and MCAR is In MAR missing data is dependent on variables of data.

For example if you are collecting age of womens some womens are not okay to expose their age like that.


3. MNAR(Missing Not at Random)::

Data is missing at randomly but here difference between  MAR and MNAR is In MNAR missing data is dependent on the variable itself.

For example if you are collecting salary of employees some employees are not okay to expose their salary like that. So in this case missing data is dependent on the variable itself.

if we are thinking in MCAR means 
the age data is missing randomly and it is not dependent on any variable in the dataset. So we can ignore the missing values or we can impute the missing values with mean or median.


if we are thinking in MAR means

thee age data is missing because some another country people are not okay to expose their age. So in this case missing data is dependent on another variable in the dataset. So we can impute the missing values with mean or median based on the distribution of the data.


if we are thinking in MNAR means

the age data is missing because some employees are not okay to expose their salary. So in this case missing data is dependent on the variable itself. So we cannot ignore the missing values or we cannot impute the missing values with mean or median because it can create bias in the dataset. So we need to handle the missing values properly based on the mechanism of missing data.
